# csvsummary (Workshop AI sandbox)

Prints count, mean and median for each numeric column of a CSV file with a header row.

```powershell
python -m csvsummary data/sample.csv
python -m unittest discover -s tests
```

This repository is the sandbox for the Workshop AI pilot: task definitions in [pilot/tasks.md](pilot/tasks.md),
the step-by-step script in [pilot/user-script.md](pilot/user-script.md).
